# Проект "Deltarune Forum"

Этот сервис позволит фанатам игры Deltarune задавать вопросы и получать на них ответы. Возможности комментирования и голосования формируют сообщество и позволяет пользователям активно помогать другим.

## О проекте

**Deltarune Forum** — это интерактивная платформа для поклонников культовой инди-игры Deltarune, разработанной Toby Fox. Сайт создан как центральный хаб для обмена знаниями, обсуждения игровых моментов и помощи друг другу в прохождении этого уникального и захватывающего приключения.

### Функциональность

Платформа предоставляет полнофункциональный механизм вопросов и ответов с интегрированной системой сообщества:

- **Задавайте вопросы** — Не понимаете механику боя? Не можете найти скрытую комнату? Опубликуйте свой вопрос и получите помощь от опытных игроков и фанатов игры.

- **Ищите ответы** — Страница новых вопросов показывает самые свежие обсуждения, а раздел "Горячие вопросы" выделяет наиболее актуальные темы с высокой активностью сообщества.

- **Фильтруйте по темам** — Система тегов позволяет быстро найти вопросы, связанные с интересующим вас аспектом игры: прохождение конкретной главы, стратегии боя, поиск секретов или обсуждение сюжета и персонажей.

- **Оценивайте контент** — Система голосования позволяет выделить наиболее полезные и качественные ответы, помогая другим пользователям сразу найти самую релевантную информацию.

- **Личный профиль** — Ведите собственный профиль, отслеживайте свою активность и становитесь известной фигурой в сообществе Deltarune.

### Почему это полезно

В отличие от обычных форумов, где обсуждения быстро теряются в архивах, структурированная система вопросов-ответов Deltarune Forum позволяет:

- Быстро найти решение именно вашей проблемы благодаря интуитивной навигации и фильтрации
- Получить несколько вариантов решения от разных игроков с разным опытом и подходом
- Помочь другим, поделившись своим опытом и знаниями об игре
- Узнать новые трюки, секреты и стратегии, которые вы могли пропустить

Платформа работает на современной архитектуре Django и выполнена в стилистике самой игры, отражая уникальный эстетический мир Deltarune, созданный Тоби Фоксом.

## Локальный запуск:

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python manage.py runserver
```

## Запуск через Docker Compose:

```bash
docker compose up --build
```

После запуска сайт доступен по адресу `http://127.0.0.1:8000/`.

## Основные URL

- `/` — список новых вопросов
- `/hot/` — список горячих вопросов
- `/tag/<tag>/` — список вопросов по тегу
- `/question/<id>/` — страница вопроса со списком ответов
- `/login/` — форма входа
- `/signup/` — форма регистрации
- `/profile/` — форма редактирования профиля
- `/ask/` — форма создания вопроса
